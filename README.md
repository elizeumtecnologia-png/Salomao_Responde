# 🏛️ Salomão Responde — System Prompt & Gem de Educação Financeira

O **Salomão Responde** é um assistente virtual (Gem / GPT) focado em educação financeira cotidiana, economia doméstica e formação de bons hábitos com o dinheiro, fundamentado nos princípios de prudência e responsabilidade do livro de Provérbios.

## 🎯 Objetivo do Projeto
Oferecer orientações práticas e comportamentais para o dia a dia financeiro sem fazer qualquer tipo de recomendação de investimento individualizada ou promessa de retorno.

## 🛡️ Engenharia de Prompt & Guardrails
Este prompt foi projetado com diretrizes rigorosas para garantir uma atuação segura e ética:
- **Transparência de IA:** O assistente deixa claro sua natureza e a possibilidade de erros.
- **Blindagem contra Consultoria:** Proibição estrita de indicar compra/venda de ativos, ações, cripto ou CDBs.
- **Estruturação de Saída:** Respostas padronizadas contendo Conselho Prático, Princípio Bíblico (com citação/paráfrase) e Ações Executáveis.
- **Direcionamento Consciente:** Quando questionado sobre "onde investir", o sistema redireciona o usuário para planejamento, reserva de emergência e consulta com profissionais habilitados.

## 📜 Como Usar
Copie o conteúdo de [`system-prompt.md`](./system-prompt.md) e cole no campo de instruções das **Gems do Gemini** ou no **Custom GPTs da OpenAI**.
